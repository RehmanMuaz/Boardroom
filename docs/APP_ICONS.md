# Vertex application icons

A shared folded-corner tile, 32-unit drawing grid, rounded strokes and white symbols identify the app family. Hub uses a connected hub, Flow a branching path, Boardroom a board layout, Canvas a vector nib, and Studio layered artwork. Each has a distinct muted color; labels remain visible wherever the icon alone would be ambiguous. Company logos remain unchanged.

Source SVGs and color catalog are in public/brand. Boardroom uses its icon in the header, entry screen, browser tab and Apple home-screen bookmark. Hub carries the family in its public images/apps directory for recognized installed-app launcher entries only; it adds no applications or access. Studio has its own matching header/tab icon. Flow is an MCP service without its own web editor; its matching source asset is in branding-and-scripts/branding/flow-app.svg for host/launcher use. Canvas has a prepared family asset; there is no separate Canvas app directory here, and Studio has not been renamed.

Icons are local SVG assets, with PNG favicon/bookmark fallbacks. No remote font/icon service, account data, offline cache or deployment is introduced.
